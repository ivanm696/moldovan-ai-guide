# 🇲🇩 Молдавский язык для AI — инструкции для всех платформ

> Большинство AI-моделей не знают, что молдавский язык исторически записывался кириллицей (Lumina Standard, МССР). Этот репозиторий учит их этому — единожды, для всех платформ сразу.

Написан один канонический файл — `AGENTS.md` — и синхронизирован в формат, который читает каждый AI-инструмент, через [TomeVault](https://tomevault.io).

## Проблема

Спроси любую AI-модель написать что-то «на молдавском» — почти всегда получишь румынскую латиницу. Это игнорирует:

- ISO 639-3 `mol` как отдельный языковой код
- Кириллическую письменную традицию МССР (Lumina Standard)
- Правила транслитерации, специфичные именно для молдавского — не совпадающие с русскими или сербскими

## Решение

Единый источник истины — [`AGENTS.md`](./AGENTS.md) — содержит:

- Полные таблицы Latin ↔ Cyrillic транслитерации (Lumina Standard)
- Правила порядка обработки (многобуквенные сочетания перед одиночными буквами)
- Известные ловушки (например `Chi → Ки`, не `Кхи`)
- Ссылку на эталонную реализацию — [`moldovan-transliterator`](https://github.com/ivanm696/moldovan-transliterator)

## Поддерживаемые платформы

| Платформа | Файл |
|---|---|
| Claude Code | `CLAUDE.md` |
| Cursor | `.cursor/rules/moldovan-language.mdc` |
| GitHub Copilot | `.github/copilot-instructions.md` |
| Windsurf | `.windsurfrules` |
| Универсальный (Codex и др.) | `AGENTS.md` |

Все файлы синхронизированы вручную из `AGENTS.md` при каждом обновлении. При подключении репозитория к [tomevault.io](https://tomevault.io) синхронизация происходит автоматически при каждом коммите.

## Как использовать

**В своём проекте:**
```bash
curl -o AGENTS.md https://raw.githubusercontent.com/ivanm696/moldovan-ai-guide/main/AGENTS.md
```
Скопируй в корень своего репозитория — большинство AI-инструментов подхватят файл автоматически.

**Через TomeVault:**
Зайди на [tomevault.io](https://tomevault.io), подключи этот репозиторий — получишь актуальную синхронизацию под любой AI-инструмент, включая те, что появятся позже.
